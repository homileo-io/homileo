Fixes from the third audit. Breaking: every `/v1` route and the socket handshake need `homileo.spaces.read` (write and `homileo.chat.admin` include it); `POST /principals/resolve` needs write; space moderators may archive, remove participants from and delete messages in `access: members` sessions they cannot read (204, no content); `DELETE /messages/:id` can answer 204; mention readers in space sessions must be able to read the space; body-parser 415s answer 400; tereo library errors answer `server_error`; deadlocks answer 409 `version_conflict`; new socket code `temporarily_unavailable` and server event `unsubscribed`; validation errors list at most 20 issues. Also: edits no longer re-parse earlier revisions (new `message_ever_mentions`), Markdown lazy lines are budgeted, `/sync` keeps stored reaction summaries and caps rows scanned per page, member removal records its events in one batch, list-order indexes, bounded provisioning lock waits, busy-database 503s for connection timeouts, no bearer token in cross-node socket fetches, sweep-based room repair, attachment size enforced by the keep job and pending placeholders capped, mention emails capped and cooled down. New env vars: `ATTACHMENT_MAX_PENDING`, `MENTION_EMAIL_COOLDOWN_SECONDS`. SDK: messages, reaction routes and `reaction.added`/`reaction.removed` carry `reactionSeq` (the reaction events also the whole summary), and clients keep the summary with the highest; `SocketUnsubscribedSchema` describes the `unsubscribed` event.

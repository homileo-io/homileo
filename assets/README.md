# Brand assets

| File                  | Use                                                                                                                          |
| --------------------- | ---------------------------------------------------------------------------------------------------------------------------- |
| `homileo-banner.svg`  | 1200×500, the README header                                                                                                  |
| `homileo-mark.svg`    | 256×256, avatars, the Helm chart icon and the standalone UI's app icons                                                      |
| `homileo-favicon.svg` | 256×256 with heavier lines, for 16–32 px: the standalone UI's favicons                                                       |
| `homileo-social.svg`  | 1280×640, the repository's social preview (`homileo-social.png` is the file GitHub takes, under _Settings → Social preview_) |

The wordmark and tagline are converted to outlines, so the SVGs need no fonts installed.

The standalone UI (`packages/homileo-ui`, plan 7) renders its icons from these SVGs.
